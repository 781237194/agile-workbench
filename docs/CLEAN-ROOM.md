# Clean-room 约定

## 目标

从零构建一个独立开源的“敏捷工作台”，不把任何上游工作台的源码、模板、文档、截图、示例项目搬进本仓库。

## 允许

- 使用公开的通用概念：项目、角色、任务、看板、评审、回执、流程图。
- 使用第三方库/运行时（Electron、DSH 等），保留其许可证。
- 根据需求重新设计数据结构、界面、交互和实现。

## 不允许

- 复制旧工作台的文件结构、源代码片段、提示词模板、CSS、文档、截图。
- 用改名、替换变量、删版权的方式把旧代码包装成新项目。
- 把旧仓库的 `LICENSE` / `NOTICE` 删除或删除作者署名后继续分发衍生代码。

## 新代码来源

本仓库的代码由本次独立实现生成；提交前用 `npm run check` 和启动自检验证。
