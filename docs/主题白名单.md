## 四、新增代码的登记规则（写入 checklist）

1. 新增/改动的界面颜色必须用 `style.css` 的主题变量；不得在 JS/HTML 写内联颜色。
2. 确需例外（第三方色板/像素对齐），当场在本文「存量登记」表补一行：`文件:行 / 颜色值 / 为什么暂不接主题 / 计划替换版本`；未登记即违规。
3. 改动区必须过对比度硬判（WCAG AA 4.5:1，深浅两套主题都测）。
4. 后续新增页面按同一 checklist 走：主题变量 + 对比度 + 1280/1680 两档截图。
