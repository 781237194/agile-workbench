# 05 · 授权、日志、索引、看板

## 一、授权（grant）

```powershell
# PM 给程序员具体授权：项目 + 动作 + 范围 + 到期 + 理由
node 团队\工具\team.mjs grant --boot <T> --to programmer1 --actions propose ^
  --scope "src/**,docs/**" --project 团队工作台改造 --expires 7d --reason "T-... 需要改这两个目录"

node 团队\工具\team.mjs grant list --boot <T>
node 团队\工具\team.mjs grant revoke --boot <T> --to programmer1 --id G-...
```

- 授权必须**具体**：项目、动作、路径 scope、到期、理由，一个都不能少。
- 没有 `propose` 授权 → `NO_GRANT`；PM 也不替人改文件。
- 授权到期前 PM 复核；过期授权 `reconcile` 会报。

## 二、日志

- 每个命令写一行事件：`状态\事件.jsonl`（seq + prev + hash 链）。
- 每天一份人读日志：`团队\日志\YYYY-MM-DD.md`。
- 事件字段：时间、角色、会话、动作、项目、目标、结果、短备注、数据。
- ⛔ 不写密钥/账号/私密内容；只记路径。
- 事件链被改 → `verify` 报 `EVENT_CHAIN`。

## 三、索引

```powershell
node 团队\工具\team.mjs index --project <项目>
```

- 每个项目根有 `项目索引.md` + `项目索引.json`。
- 索引包含：项目说明（人工块）、规矩、文件清单（大小/哈希/归属）、任务摘要、最近提交、维护命令。
- **先读索引再找文件**；找文件只用 `find`。
- apply 后自动重建索引；手工改动文件后也要重建。

## 四、看板

```powershell
node 团队\工具\team.mjs board          # 生成 看板.md + 看板.html + 看板.json
```

看板显示：

- 需求看板（优先级、状态、子任务、验收标准）
- 进行中任务
- 提案 / 每个成员的评审 / 签字 / 提交
- 回执（谁回给谁、备注、时间）
- 项目文件（可点开）
- 成员工作量（发消息/评审/签字/提交/回执）
- 试点门槛

工作台顶栏「团队看板」按钮会打开 `团队\看板.html`。

## 五、验证

```powershell
node 团队\工具\team.mjs verify            # 全量
node 团队\工具\team.mjs verify --project <项目>
```

检查：事件链、提案哈希、目标文件哈希、评审/签字摘要、owner 通道、锁、授权过期。任何 FAIL 都要停手。
